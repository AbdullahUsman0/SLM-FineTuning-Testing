# Downloadable experimental v8 adapter

The completed fixed final-step adapter is available as a verified GitHub prerelease:

https://github.com/AbdullahUsman0/SLM-FineTuning-Testing/releases/tag/v8-adapter-20261022

Read training-completed-20261023T002215Z/ADAPTER_RELEASE.json for the exact ZIP/checksum links, file/member SHA-256 values and publication verification. The portable download_adapter.py in that folder downloads, verifies and extracts it into a NEW local directory. LOCAL_CODEX_HANDOFF.md provides the paper-update instructions for the other PC.

This prerelease was prepared after training/validation completed, while development evaluation was still running. It contains the experimental final-step adapter and training provenance, not completed behavioral comparison results. Later comparison summaries and raw journals belong in this parent results folder when the worker/followup finish.

The followup's later adapter-package.json describes a separate ZIP created in the training PC's Downloads folder after the diagnostic. A statement that this later local ZIP was not uploaded does not withdraw the distinct prerelease linked above. Compare filenames and hashes. Neither package includes base weights or resumable optimizer checkpoints. No model winner or independently reviewed final-test result is established by this release.
